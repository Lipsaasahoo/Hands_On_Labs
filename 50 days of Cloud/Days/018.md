# Day 18: Create a Read-Only IAM Policy for EC2 Console Access

## Introduction

### What is an IAM Policy?

An **AWS Identity and Access Management (IAM) Policy** is a JSON document that defines permissions for AWS resources. It specifies **who can perform what actions on which resources**.

IAM policies are attached to **users, groups, or roles** to grant or restrict access to AWS services.

---

## Why are IAM Policies Needed?

IAM policies help organizations securely manage access to AWS resources by granting only the permissions users require.

Common use cases include:

- Providing read-only access to auditors.
- Granting developers limited permissions.
- Restricting administrative operations.
- Enforcing the Principle of Least Privilege.
- Improving security by preventing unauthorized changes.

Instead of giving users full administrator access, organizations create custom policies that allow only the required actions.

---

## What is Read-Only Access?

A **Read-Only** policy allows users to **view AWS resources** without making any changes.

For this task, users should be able to:

- View EC2 Instances
- View Amazon Machine Images (AMIs)
- View EBS Snapshots

However, they cannot:

- Launch or terminate EC2 instances
- Create or delete snapshots
- Modify EC2 resources

---

## How IAM Policies Work

```text
Administrator
        │
        ▼
Create IAM Policy
        │
        ▼
Attach Policy
(User / Group / Role)
        │
        ▼
User Signs In
        │
        ▼
Allowed AWS Actions
```

# Steps (AWS Management Console - Visual Editor)

## Step 1: Open the IAM Console

1. Sign in to the **AWS Management Console**.
2. Navigate to:

```text
Services → IAM
```

---

## Step 2: Navigate to Policies

From the left navigation pane, select:

```text
Policies
```

Click:

```text
Create policy
```

---

## Step 3: Configure the Policy Using the Visual Editor

Select the **Visual** editor.

### Choose the AWS Service

| Setting | Value |
|----------|-------|
| Service | EC2 |

---

### Configure Permissions

Expand the **Read** access level.

Search and select only the following permissions:

- ✅ DescribeInstances
- ✅ DescribeImages
- ✅ DescribeSnapshots

> **Note:** Do **not** select **All read actions**, as the task only requires permission to view EC2 Instances, AMIs, and Snapshots.

---

### Configure Resources

Under **Resources**, leave the default option:

```text
All resources
```

Click:

```text
Next
```

---

## Step 4: Configure Policy Details

Enter:

| Setting | Value |
|----------|-------|
| Policy Name | `sample_iampolicy` |

(Optional) Add a description if required.

Click:

```text
Create policy
```

---

## Step 5: Verify the Policy

Navigate to:

```text
IAM → Policies
```

Verify that the following policy exists:

```text
sample_iampolicy
```

The task is complete once the policy appears in the IAM Policies list.

# Alternative Method: Using the JSON Editor

Instead of using the Visual Editor, you can create the same IAM policy by writing the policy in JSON format.

## Step 1: Open the JSON Editor

While creating a new IAM policy:

1. Navigate to:

```text
IAM → Policies → Create Policy
```

2. Select the **JSON** tab.

3. Remove the default policy and paste the following JSON:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "EC2ReadOnlyAccess",
      "Effect": "Allow",
      "Action": [
        "ec2:DescribeInstances",
        "ec2:DescribeImages",
        "ec2:DescribeSnapshots"
      ],
      "Resource": "*"
    }
  ]
}
```

Click:

```text
Next
```

---

```text
Create policy
```

Navigate to:


Verify that the following policy exists:

# Using the AWS CLI (Optional)

## Step 1: Create the Policy JSON File

Create a file named:

```text
ec2-readonly-policy.json
```

Paste the following content:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "ec2:DescribeInstances",
        "ec2:DescribeImages",
        "ec2:DescribeSnapshots"
      ],
      "Resource": "*"
    }
  ]
}
```

---

## Step 2: Create the IAM Policy

```sh
aws iam create-policy --policy-name sample_iampolicy --policy-document file://ec2-readonly-policy.json
```

---

## Step 3: Verify the Policy

```sh
aws iam list-policies --scope Local
```

or

```sh
aws iam get-policy --policy-arn <POLICY_ARN>
```

Replace `<POLICY_ARN>` with the ARN of the newly created policy.

---

# Things to Remember

- IAM is a **global AWS service**, so policies are not created in a specific region.
- IAM policies are written using **JSON**.
- A policy does not grant permissions until it is attached to a user, group, or role.
- The `Describe*` API actions provide read-only access to AWS resources.
- Follow the **Principle of Least Privilege** by granting only the permissions required.
