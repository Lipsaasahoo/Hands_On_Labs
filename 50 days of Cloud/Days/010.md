# Day 10: Associate an Elastic IP with an EC2 Instance

## Introduction

### What is an Elastic IP?

An **Elastic IP (EIP)** is a static public IPv4 address provided by AWS. Unlike the default public IP assigned to an EC2 instance, an Elastic IP remains associated with your AWS account until you release it.

You can associate or re-associate an Elastic IP with different EC2 instances whenever needed, making it ideal for production environments.

---

## Why is an Elastic IP Needed?

By default, when an EC2 instance is stopped and started, its public IPv4 address changes (unless an Elastic IP is attached).

This can cause issues such as:

- Broken DNS records
- Failed client connections
- Application downtime
- Reconfiguration of external services

An **Elastic IP** solves this problem by providing a **permanent public IP address** that remains the same even if the instance is restarted.

Common use cases include:

- Hosting production web servers
- Public-facing APIs
- Bastion (Jump) Hosts
- Mail servers
- Any application requiring a fixed public IP address

> **Note:** AWS charges for Elastic IPs that are allocated but not associated with a running EC2 instance.

# Task

There is:

- An EC2 instance named **`nautilus-ec2`**
- An Elastic IP named **`nautilus-ec2-eip`**

Both are located in the **`us-east-1`** region.

Associate the **`nautilus-ec2-eip`** Elastic IP with the **`nautilus-ec2`** EC2 instance.

---

# Steps (AWS Management Console)

## Step 1: Open the EC2 Console

1. Sign in to the **AWS Management Console**.
2. Navigate to:

```
Services → EC2
```

3. Ensure the selected AWS Region is:

```
us-east-1
```

---

## Step 2: Verify the EC2 Instance

Open **Instances** from the left navigation pane.

Locate the instance named:

```text
nautilus-ec2
```

Ensure the instance is in the **Running** state.

---

## Step 3: Open the Elastic IPs Page

From the left navigation pane, under **Network & Security**, select:

```
Elastic IPs
```

Locate the Elastic IP named:

```text
nautilus-ec2-eip
```

---

## Step 4: Associate the Elastic IP

1. Select **`nautilus-ec2-eip`**.
2. Click **Actions**.
3. Select:

```
Associate Elastic IP address
```

Configure the following:

| Setting | Value |
|----------|-------|
| Resource Type | Instance |
| Instance | `nautilus-ec2` |
| Private IP Address | Leave the default selection |

Click **Associate**.

AWS will display a confirmation message indicating that the Elastic IP has been successfully associated.

---

## Step 5: Verify the Association

Navigate back to:

```
EC2 → Instances
```

Select the **`nautilus-ec2`** instance.

Under the **Details** tab, verify that the **Public IPv4 Address** matches the associated Elastic IP address.

You can also verify the association from the **Elastic IPs** page, where the **Associated Instance** column should display:

```text
nautilus-ec2
```

---

# Using the AWS CLI (Optional)

## List Elastic IPs

```sh
aws ec2 describe-addresses --region us-east-1
```

Note the **AllocationId** of the Elastic IP.

---

## Associate the Elastic IP

```sh
aws ec2 associate-address \
    --instance-id <INSTANCE_ID> \
    --allocation-id <ALLOCATION_ID> \
    --region us-east-1
```

Replace:

- `<INSTANCE_ID>` with the EC2 instance ID.
- `<ALLOCATION_ID>` with the Elastic IP Allocation ID.

---

## Verify the Association

```sh
aws ec2 describe-addresses --region us-east-1
```

The output should show that the Elastic IP is associated with the correct EC2 instance.
