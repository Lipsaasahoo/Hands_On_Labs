# Day 17: Terminate an Amazon EC2 Instance

## Introduction

### What is EC2 Instance Termination?

**Terminating an Amazon EC2 instance** permanently deletes the virtual server from your AWS account. Once an instance is terminated, it cannot be restarted or recovered.

When an EC2 instance is terminated:

- The instance enters the **Terminated** state.
- The instance's compute resources are released.
- The root EBS volume is deleted if the **Delete on termination** option is enabled (default for most root volumes).
- Any attached data volumes configured **not** to delete on termination remain available.

Terminating unused instances helps reduce AWS costs and keeps your cloud environment clean and efficient.

---

## Why Terminate an EC2 Instance?

There are several situations where terminating an EC2 instance is necessary:

- Removing unused or temporary servers.
- Reducing AWS infrastructure costs.
- Cleaning up development or testing environments.
- Replacing old instances with updated configurations.
- Decommissioning applications that are no longer needed.

Since AWS charges for running compute resources, terminating unused instances helps optimize cloud spending.

## EC2 Instance Lifecycle

```text
Launch
   │
   ▼
Pending
   │
   ▼
Running
   │
   ▼
Stopping
   │
   ▼
Stopped
   │
   ▼
Terminating
   │
   ▼
Terminated
```

> **Note:** Once an instance reaches the **Terminated** state, it cannot be restarted.

Terminate the existing EC2 instance with the following details:

# Steps (AWS Management Console)

## Step 1: Open the EC2 Console

1. Sign in to the **AWS Management Console**.
2. Navigate to:

```text
Services → EC2
```

3. Ensure the selected AWS Region is:

```text
us-east-1
```

---

## Step 2: Locate the EC2 Instance

Navigate to:

```text
EC2 → Instances
```

Locate the instance:

```text
devops-ec2
```

Select the instance.

---

## Step 3: Terminate the Instance

Click:

```text
Instance State → Terminate Instance
```

or

```text
Actions → Instance State → Terminate Instance
```

When prompted for confirmation, click:

```text
Terminate
```

AWS begins terminating the instance.

---

## Step 4: Verify the Instance State

After a few moments, the instance state changes as follows:

```text
Running
      ↓
Shutting-down
      ↓
Terminated
```

Verify that the final state is:

```text
Terminated
```

The task is complete once the instance reaches the **Terminated** state.

# Using the AWS CLI (Optional)

## Find the Instance ID

```sh
aws ec2 describe-instances --filters "Name=tag:Name,Values=devops-ec2" --region us-east-1
```

---

## Terminate the Instance

```sh
aws ec2 terminate-instances --instance-ids <INSTANCE_ID> --region us-east-1
```

Replace:

- `<INSTANCE_ID>` with the EC2 instance ID.

---

## Verify the Instance State

```sh
aws ec2 describe-instances --instance-ids <INSTANCE_ID> --region us-east-1
```

Expected output:

```text
State: terminated
```

---

# Things to Remember

- Terminating an EC2 instance is **irreversible**.
- A terminated instance **cannot** be restarted.
- By default, the root EBS volume is deleted when the instance is terminated.
- Additional EBS volumes configured with **Delete on termination = No** remain available after termination.
- Elastic IP addresses associated with the instance are disassociated and may incur charges if left unassociated.
