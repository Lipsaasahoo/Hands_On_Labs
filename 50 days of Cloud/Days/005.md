# Day 5: Create GP3 Volume

## Task
Create a volume with the following requirements:

Name of the volume should be `nautilus-volume`.
Volume type must be `gp3`.
Volume size must be `2 GiB`.

## Why needed
Initially when we create an instance we provide a storage value like 8gb. Oviously when then the multiple applications in that instances takes up space we need to scale the storage and add aditional space. For this we use EBS (Elastic block storage) where it allows us to create volumes.

## Steps

1. Open AWS console and navigate to EC2.
2. Click Volumes in Elastic Block Storage.
3. Click new `Create Volume`.
4. Add the required configuration like the availability zone, volume type, Size etc.
![alt text](<../Images/005-a.png>)
5. Click Create vloume, and now the volume is created.
![alt text](<../Images/005-b.png>)
6. By default the name of the volume is not present, in the volumes catalogue we can add the name to the volume too.
