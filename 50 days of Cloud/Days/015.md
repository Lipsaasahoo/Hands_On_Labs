# Day 15: Create a Snapshot of an Amazon EBS Volume

## Introduction

### What is an Amazon EBS Snapshot?

An **Amazon EBS Snapshot** is a point-in-time backup of an Amazon Elastic Block Store (EBS) volume. Snapshots are stored in Amazon S3 (managed internally by AWS) and can be used to restore data or create new EBS volumes.

Unlike traditional backups, EBS snapshots are **incremental**. This means that after the first full snapshot, AWS stores only the blocks that have changed since the previous snapshot, reducing storage costs and backup time.

---

## Why are EBS Snapshots Needed?

Snapshots provide a reliable way to back up important data and recover from failures.

Common use cases include:

- Regular data backups
- Disaster recovery
- Restoring accidentally deleted data
- Creating new EBS volumes
- Migrating data between Availability Zones or Regions
- Creating AMIs (Amazon Machine Images)

Snapshots are a key component of backup and disaster recovery strategies in AWS.

# Task

Create a snapshot of the existing EBS volume:

```text
nautilus-vol
```

Requirements:

| Setting | Value |
|----------|-------|
| Volume | `nautilus-vol` |
| Snapshot Name | `nautilus-vol-ss` |
| Description | `nautilus Snapshot` |
| Region | `us-east-1` |
| Final Status | Completed |

# Steps (AWS Management Console)

## Step 1: Open the EC2 Console

1. Sign in to the **AWS Management Console**.
2. Navigate to:

```text
Services → EC2
```

3. Ensure the selected AWS Region is:

```text
us-east-1
```

---

## Step 2: Locate the EBS Volume

From the left navigation pane, select:

```text
Elastic Block Store → Volumes
```

Locate the volume:

```text
nautilus-vol
```

Select the volume.

---

## Step 3: Create the Snapshot

With the volume selected:

1. Click **Actions**.
2. Select:

```text
Create Snapshot
```

Configure the following:

| Setting | Value |
|----------|-------|
| Description | `nautilus Snapshot` |

Under **Tags**, add:

| Key | Value |
|-----|-------|
| Name | `nautilus-vol-ss` |

> **Note:** EBS snapshots do not have a separate "Name" field. The snapshot name is typically assigned using the **Name** tag.

Click:

```text
Create Snapshot
```

AWS begins creating the snapshot.

---

## Step 4: Verify the Snapshot

Navigate to:

```text
Elastic Block Store → Snapshots
```

Locate:

```text
nautilus-vol-ss
```

Initially, the snapshot state will be:

```text
Pending
```

Wait until the status changes to:

```text
Completed
```

The task is complete once the snapshot reaches the **Completed** state.

# Using the AWS CLI (Optional)

## Find the Volume ID

```sh
aws ec2 describe-volumes \
    --filters "Name=tag:Name,Values=nautilus-vol" \
    --region us-east-1
```

---

## Create the Snapshot

```sh
aws ec2 create-snapshot \
    --volume-id <VOLUME_ID> \
    --description "nautilus Snapshot" \
    --tag-specifications 'ResourceType=snapshot,Tags=[{Key=Name,Value=nautilus-vol-ss}]' \
    --region us-east-1
```

Replace:

- `<VOLUME_ID>` with the EBS Volume ID.

The command returns a **Snapshot ID**.

---

## Verify the Snapshot Status

```sh
aws ec2 describe-snapshots \
    --snapshot-ids <SNAPSHOT_ID> \
    --region us-east-1
```

Expected output:

```text
State: completed
```

# Things to Remember

- The first EBS snapshot is a **full backup**; subsequent snapshots are **incremental**.
- Snapshots are stored in Amazon S3 and managed automatically by AWS.
- You can create a new EBS volume from a snapshot at any time.
- Snapshot creation begins immediately, but the snapshot must reach the **Completed** state before it can be fully used for recovery or creating new volumes.
