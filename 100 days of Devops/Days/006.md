## what is cron job

A cron job is a time-based job scheduler in Unix-like operating systems. It automates repetitive tasks to run in the background at specific intervals, times, or dates.How It WorksThe Daemon: A background service called crond constantly runs on the system.The Checklist: Every minute, crond checks the system's configuration files (called crontabs).The Execution: If the current time matches a scheduled task, crond automatically runs the associated command or script.Real-World Use CasesBackups: Generating daily database backups at 2:00 AM.Maintenance: Clearing out system temporary logs every weekend.Updates: Checking for and downloading security patches every night.Reminders: Sending automated weekly email reports to managers.Key BenefitsEfficiency: Eliminates the human error of forgetting routine maintenance.Reliability: Executes tasks exactly on schedule without manual intervention.Resource Management: Shifts heavy processing tasks to low-traffic hours (like midnight)
## Task
On all Nautilus app servers:

Install cronie package and start the crond service.
Create a cron job for the root user to run every 5 minutes: echo hello > /tmp/cron_text

### 5. Opened the crontab editor:

```sh
sudo crontab -e
```
Added this line to root’s crontab to run the job every 5 minutes

```sh
*/5 * * * * echo hello > /tmp/cron_text
```
Breakdown:

- */5 → run every 5 minutes.
- * * * → no restrictions on hour, day, month, or day of week.
- echo hello → command that outputs the text "hello".
- /tmp/cron_text → writes that output to the file /tmp/cron_text, overwriting it each time.

This means that every 5 minutes, the cron job replaces the contents of /tmp/cron_text with the word hello.

### 6. Saved and verified the cron job

Saved and exited the crontab editor.

Verified the cron job is scheduled:
```sh

```
