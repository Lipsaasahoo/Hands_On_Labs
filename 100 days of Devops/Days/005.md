# Day 5: SELinux Installation and Configuration

## Task

- Install the required SELinux packages.
- Permanently disable SELinux for the time being; it will be re-enabled after the necessary configuration changes.
- No need to reboot the server, as a scheduled maintenance reboot is already planned for tonight.
- Disregard the current runtime status of SELinux via the command line. The required final state **after the reboot** should be **disabled**.

---

## Why this is Needed

**SELinux (Security-Enhanced Linux)** is a Linux security framework that controls what users, processes, and applications are allowed to access on the system.

SELinux has two different states:

- **Current (Runtime) State** – The state SELinux is currently running in.
- **Permanent (Configuration) State** – The state SELinux will use after the next system reboot.

---

## Steps

### 1. SSH into the Linux Server

```sh
ssh username@servername
```

---

### 2. Identify the Operating System / Linux Distribution

```sh
cat /etc/os-release
```

![OS Information](../Images/005-a.png)

Different Linux distributions use different package managers.

| Distribution | Package Manager |
|--------------|-----------------|
| CentOS / RHEL | `dnf` or `yum` |
| Ubuntu | `apt` |

Since the server is running **CentOS Stream**, use **dnf** to install the required packages.

---

### 3. Install the SELinux Packages

```sh
sudo dnf install -y selinux-policy selinux-policy-targeted policycoreutils
```

#### Explanation

- `sudo` → Runs the command with administrator privileges.
- `dnf` → Package manager for CentOS/RHEL.
- `install` → Installs the specified packages.
- `-y` → Automatically answers **Yes** to installation prompts.

#### Packages Installed

| Package | Purpose |
|---------|---------|
| `selinux-policy` | Installs the SELinux security policy files |
| `selinux-policy-targeted` | Installs the default targeted SELinux policy |
| `policycoreutils` | Provides utilities to manage and troubleshoot SELinux |

---

### 4. Verify the Packages are Installed

List all installed SELinux-related packages:

```sh
dnf list installed | grep selinux
```

#### Explanation

- `dnf list installed` → Lists all installed packages.
- `grep selinux` → Filters the output to display only SELinux-related packages.

To verify a specific package:

```sh
rpm -q policycoreutils
```

#### Explanation

- `rpm` → Low-level RPM package management tool.
- `-q` (`query`) → Checks whether the package is installed.
- If installed, it displays the package version.
- If not installed, it reports that the package is missing.

---

### 5. Check the SELinux Status

SELinux has two different states that should be understood separately.

#### 5.1 Check the Current (Runtime) State

```sh
sestatus
```

Example output:

```text
SELinux status:                 disabled
```

This shows the **current runtime status** only.

---

#### 5.2 Check the Permanent (Configuration) State

The SELinux configuration file is located at:

```text
/etc/selinux/config
```

Open the configuration file:

```sh
sudo vim /etc/selinux/config
```

Locate the following line:

```text
SELINUX=enforcing
```

Change it to:

```text
SELINUX=disabled
```

Save and exit the editor.

This change ensures that **SELinux remains disabled after the next system reboot**, even if the current runtime status is different.

---

## Summary

1. Connect to the server using SSH.
2. Identify the Linux distribution.
3. Install the required SELinux packages.
4. Verify that the packages are installed.
5. Check the current SELinux runtime status using `sestatus`.
6. Edit `/etc/selinux/config`.
7. Set:

```text
SELINUX=disabled
```

8. Save the file. After the scheduled reboot, SELinux will start in the **disabled** state.
