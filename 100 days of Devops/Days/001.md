# Day 1 - Linux User Setup with Non-Interactive Shell

## Task 
Create user with non ineractive shell for organization on a specifif server

## Steps
1. Login the application server using `SSH`:

    ```sh 
    ssh user@app-server-ip 
    ssh user@server-name
    ```
    > It will ask User password, Enter the password

2. Once logged into the server, run the command

    ```sh
    sudo useradd -m -s /sbin/nologin user_name
    ```
    `-m`: for user home directory. will create a directory with user_name under /home

    `-s`: for shell , its nologin shell

3. Verify Output

    ```sh
    cat /etc/passwd
    ```
    It will display the list of users where in the bottom we will have the user that we created.

    Try login using the user created:

    ```sh
    sudo su user_name
    ```

    output: `This account is currently not available.`

## Common Issues Faced

- **Permission denied**: Ensure you have sudo privileges
- **User already exists**: Check existing users with `cat /etc/passwd | grep username`
- **Shell not found**: Verify `/usr/sbin/nologin` exists on your system

## Key learnings

- User types : Regular users, System users, Service accounts
- Shell types : `/bin/bash` (interactive), `/sbin/nologin` (non-interactive), `/bin/false` (deny access)
- Service accounts should use non-interactive shells
- Verify if user exists
