# Day 10: Linux Bash Scripts

## Introduction

### What is a Bash Script?

A **Bash script** is a file containing a sequence of Linux commands that are executed automatically by the **Bash (Bourne Again Shell)** interpreter.

Instead of manually typing the same commands repeatedly, you can save them in a script and execute them with a single command.

Bash scripting is one of the most fundamental skills for Linux System Administrators and DevOps Engineers because it enables **automation**, **consistency**, and **efficiency**.

---

## Why are Bash Scripts Needed?

In real-world environments, administrators perform many repetitive tasks such as:

- Creating backups
- Archiving logs
- Monitoring servers
- Deploying applications
- Cleaning temporary files
- Managing users
- Restarting services
- Scheduling recurring tasks using Cron

Performing these tasks manually is:

- Time-consuming
- Error-prone
- Difficult to scale

A Bash script automates these tasks, ensuring they execute the same way every time.

---

## Real-World Use Cases

Bash scripts are commonly used for:

- Automated backups
- Website content archiving
- Database backups
- Log rotation and cleanup
- User and permission management
- Service monitoring
- Application deployment
- CI/CD automation
- System health checks
- File synchronization between servers

## Task

Create a Bash script named **`beta_archive.sh`** on **App Server 3** that performs the following tasks:

- Create a ZIP archive named **`xfusioncorp_beta.zip`** from:

```text
/var/www/html/beta
```

- Save the archive in:

```text
/archives
```

- Copy the archive to the Nautilus Storage Server in:

```text
/archives
```

Additional requirements:

- Place the script in:

```text
/scripts
```

- Configure password-less SSH so the script does not prompt for a password.
- Do **not** use `sudo` inside the script.
- Install the `zip` package **outside** the script.

---

# Steps

## Step 1: Connect to App Server 3

```sh
ssh banner@stapp03
```

---

## Step 2: Install the ZIP Package

Before creating the archive, ensure the `zip` package is installed.

For CentOS/RHEL:

```sh
sudo yum install -y zip
```

For Ubuntu/Debian:

```sh
sudo apt install -y zip
```

Verify the installation:

```sh
zip -v
```

---

## Step 3: Verify the `/scripts` Directory

Check whether the `/scripts` directory already exists.

```sh
ls -ld /scripts
```

If it exists, you will see output similar to:

```text
drwxrwxrwx 2 root root ... /scripts
```

If it does not exist, create it:

```sh
mkdir -p /scripts
```

> **Why `mkdir -p`?**  
> The `-p` option creates the directory only if it doesn't already exist, making it safe to run multiple times.

---

## Step 4: Create the Script

Create the script:

```sh
vi /scripts/beta_archive.sh
```

Add the following content:

```bash
#!/bin/bash

# Create archive directory if it doesn't exist
mkdir -p /archives

# Create ZIP archive
zip -r /archives/xfusioncorp_beta.zip /var/www/html/beta

# Copy archive to the Nautilus Storage Server
scp /archives/xfusioncorp_beta.zip banner@ststor01:/archives/
```

Save and exit.

---

## Step 5: Make the Script Executable

Grant execute permission.

```sh
chmod +x /scripts/beta_archive.sh
```

Verify:

```sh
ls -l /scripts/beta_archive.sh
```

Example output:

```text
-rwxr-xr-x beta_archive.sh
```

---

## Step 6: Configure Password-less SSH

Since the script uses `scp`, it must copy the archive without asking for a password.

### Generate an SSH Key Pair

```sh
ssh-keygen -t rsa -b 2048
```

Press **Enter** for:

- File location
- Passphrase
- Confirm passphrase

This creates:

```text
~/.ssh/id_rsa
~/.ssh/id_rsa.pub
```

---

### Copy the Public Key to the Storage Server

```sh
ssh-copy-id banner@ststor01
```

Enter the password **once**.

The public key is copied to:

```text
~/.ssh/authorized_keys
```

on the Storage Server.

---

### Test Password-less SSH

```sh
ssh banner@ststor01
```

The login should occur **without prompting for a password**.

Exit the session:

```sh
exit
```

---

## Step 7: Execute the Script

Run the script:

```sh
/scripts/beta_archive.sh
```

The script will:

1. Create the ZIP archive.
2. Store it locally.
3. Copy it to the Storage Server.

---

## Step 8: Verify the Archive

### On App Server 3

```sh
ls -l /archives
```

Expected output:

```text
xfusioncorp_beta.zip
```

---

### On the Storage Server

```sh
ssh banner@ststor01
```

Check:

```sh
ls -l /archives
```

Expected output:

```text
xfusioncorp_beta.zip
```

This confirms the archive was successfully copied.

# Final Script

```bash
#!/bin/bash

# Create archive directory if it doesn't exist
mkdir -p /archives

# Create ZIP archive
zip -r /archives/xfusioncorp_beta.zip /var/www/html/beta

# Copy archive to the Storage Server
scp /archives/xfusioncorp_beta.zip banner@ststor01:/archives/
```

---

# Script Breakdown

| Command | Purpose |
|----------|---------|
| `#!/bin/bash` | Specifies the Bash interpreter |
| `mkdir -p /archives` | Creates the archive directory if it doesn't exist |
| `zip -r` | Creates a recursive ZIP archive |
| `scp` | Securely copies the archive to the remote server |
