# Day 11: Deploy a Java Application on Apache Tomcat

## Introduction

### What is Apache Tomcat?

**Apache Tomcat** is an open-source web server and **Java Servlet Container** developed by the Apache Software Foundation. It is used to deploy and run Java-based web applications packaged as **WAR (Web Application Archive)** files.

Unlike Apache HTTP Server or Nginx, which primarily serve static content, Tomcat is specifically designed to run Java Servlets and JavaServer Pages (JSP).

---

## Why is Tomcat Needed?

Java web applications cannot run on their own—they require a **Servlet Container** like Tomcat to execute Java code and serve web pages.

Tomcat is commonly used for:

- Deploying Java web applications
- Hosting REST APIs
- Running enterprise Java applications
- Serving JSP and Servlet-based websites
- Hosting Spring MVC and Spring Boot WAR deployments

---

## What is a WAR File?

A **WAR (Web Application Archive)** is a compressed package containing everything required to run a Java web application.

It typically contains:

- Java classes
- JSP pages
- HTML, CSS, and JavaScript files
- Configuration files
- External libraries

When a WAR file is copied to Tomcat's **webapps** directory, Tomcat automatically extracts and deploys it.

> **Note:** If the application is named **ROOT.war**, it is deployed as the default application and can be accessed directly using the server's base URL.

---

# Task

Configure **App Server 3** with the following requirements:

- Install Apache Tomcat.
- Configure Tomcat to run on **port 8084**.
- Copy the `ROOT.war` file from the Jump Host (`/tmp/ROOT.war`) to App Server 3.
- Deploy the application.
- Verify that the application is accessible at:

```text
http://stapp03:8084
```

---

# Steps

## Step 1: Copy the WAR File from the Jump Host

The application file is available on the Jump Host in `/tmp`.

Copy it to App Server 3.

```sh
scp /tmp/ROOT.war banner@stapp03:/tmp
```

---

## Step 2: Connect to App Server 3

```sh
ssh banner@stapp03
```

---

## Step 3: Install Apache Tomcat

Update the package repository.

```sh
sudo yum update -y
```

Install Tomcat.

```sh
sudo yum install -y tomcat
```

---

## Step 4: Configure Tomcat to Run on Port 8084

Open the Tomcat configuration file.

```sh
sudo vi /etc/tomcat/server.xml
```

Locate the default connector:

```xml
<Connector port="8080" protocol="HTTP/1.1" ... />
```

Change it to:

```xml
<Connector port="8084" protocol="HTTP/1.1" ... />
```

Save and exit.

---

## Step 5: Deploy the Application

Copy the WAR file into Tomcat's deployment directory.

```sh
sudo cp /tmp/ROOT.war /usr/share/tomcat/webapps/
```

> **Note:** `/usr/share/tomcat/webapps` is a symbolic link to `/var/lib/tomcat/webapps`, so copying the WAR file here deploys it correctly.

Since the file is named **ROOT.war**, Tomcat automatically deploys it as the root application.

---

## Step 6: Start and Enable Tomcat

Start Tomcat and enable it to start automatically after system reboot.

```sh
sudo systemctl enable --now tomcat
```

Verify the service:

```sh
sudo systemctl status tomcat
```

Expected output:

```text
Active: active (running)
```

---

## Step 7: Verify the Deployment

Check that the application was deployed successfully.

```sh
ls -l /var/lib/tomcat/webapps
```

Expected output:

```text
ROOT
ROOT.war
```

The presence of the **ROOT/** directory indicates that Tomcat successfully extracted and deployed the application.

---

## Step 8: Verify the Application

Test the application locally.

```sh
curl http://localhost:8084
```

Or using the server hostname:

```sh
curl http://stapp03:8084
```

Expected output:

```text
SampleWebApp
```

This confirms that:

- Tomcat is running.
- The application has been deployed successfully.
- The application is accessible directly from the base URL.

# Troubleshooting

## Check Tomcat Service

```sh
sudo systemctl status tomcat
```

---

## Verify the Configured Port

```sh
grep Connector /etc/tomcat/server.xml
```

Expected output:

```xml
<Connector port="8084" protocol="HTTP/1.1"
```

---

## Verify WAR Deployment

```sh
ls -l /var/lib/tomcat/webapps
```

Expected:

```text
ROOT
ROOT.war
```

If only `ROOT.war` exists, the application has not been deployed successfully.

---

## Check Tomcat Logs

```sh
sudo journalctl -u tomcat -n 50 --no-pager
```

or

```sh
sudo tail -50 /var/log/tomcat/catalina.out
```

These logs help identify deployment or configuration issues.
